Bölüm 01

Arduino UNO'nun pinleri

Arduino UNO, üzerinde ATmega328P mikrodenetleyicisi bulunan bir geliştirme kartıdır. 5 V ile çalışır, 16 MHz hızındadır. Dış dünyayla iletişimi kartın kenarlarındaki pinler (soketler) üzerinden kurar. Bir LED yakmak, bir butonu okumak ya da bir sensörden değer almak için önce hangi pinin ne işe yaradığını bilmemiz gerekir.

Dijital pinler (0–13)

Kartın üst kenarındaki 14 pin dijital giriş/çıkış pinidir. Dijital pin yalnızca iki durum bilir: HIGH (5 V, mantıksal 1) ve LOW (0 V, mantıksal 0). Bu pinleri LED yakmak gibi çıkış işlerinde ya da buton okumak gibi giriş işlerinde kullanırız.

  • 0 (RX) ve 1 (TX): Bilgisayarla seri haberleşme (USB) için kullanılır. Program yüklerken sorun çıkarmamak için bu pinlere mümkünse devre bağlamayın.
  • 13: Kart üzerindeki L etiketli LED'e bağlıdır. Kodda LED_BUILTIN adıyla da kullanılabilir. Devre kurmadan ilk denemeyi bu LED ile yapabilirsiniz.

PWM pinleri (~3, ~5, ~6, ~9, ~10, ~11)

Numarasının yanında ~ (tilde) işareti olan altı dijital pin PWM (Pulse Width Modulation, darbe genişlik modülasyonu) çıkışı verebilir. Bu pinler 5 V'u çok hızlı açıp kapatarak sanki arada bir gerilim varmış gibi davranır. LED parlaklığı ya da motor hızı ayarlamak için kullanılır. analogWrite() fonksiyonu yalnızca bu pinlerde çalışır; ayrıntısı Bölüm 11'de.

Analog giriş pinleri (A0–A5)

Kartın alt sağ köşesindeki A0–A5 pinleri analog giriş pinleridir. 0 ile 5 V arasındaki herhangi bir gerilimi ölçüp 0–1023 arasında bir sayıya çevirirler. Potansiyometre, LDR (ışık sensörü), sıcaklık sensörü gibi kademeli değer veren elemanlar bu pinlere bağlanır. Gerekirse A0–A5 normal dijital pin gibi de kullanılabilir.

Karıştırılan nokta

UNO'da analog çıkış pini yoktur. "Analog" pinler sadece okuma (giriş) yapar. Ayarlı çıkış gerektiğinde ~ işaretli PWM pinleri kullanılır.

Güç pinleri

Akım sınırı

Bir dijital pinden çekilebilecek güvenli akım yaklaşık 20 mA'dir (mutlak üst sınır 40 mA). Bu yüzden LED'ler her zaman seri bir dirençle (220–330 Ω) bağlanır. Motor, röle bobini gibi yükler doğrudan pine bağlanmaz; araya transistör veya sürücü kartı konur.

Programın iskeleti: void setup() ve void loop()

Arduino'da yazdığımız programa sketch denir. Her sketch'te mutlaka iki fonksiyon bulunur. void kelimesi, bu fonksiyonların geriye bir değer döndürmediğini belirtir.

setup()
Kart açıldığında veya resetlendiğinde yalnızca bir kez çalışır. Pin ayarları, seri haberleşmenin başlatılması gibi hazırlıklar burada yapılır.

loop()
setup() bittikten sonra sonsuz döngü hâlinde tekrar tekrar çalışır. Buton okuma, LED yakma gibi sürekli yapılacak işler buraya yazılır. Saniyede binlerce kez dönebilir.

void setup() {
  // Buraya yazılan kodlar bir kez çalışır
}

void loop() {
  // Buraya yazılan kodlar sürekli tekrar eder
}

Yazım kuralları

  • Her komut noktalı virgül ; ile biter.
  • Fonksiyonun içeriği süslü parantezler { } arasına yazılır.

Bölüm 03

Değişkenler

Neden değişkenlere ihtiyaç duyarız?

Değişken, bir değeri bellekte saklamak için kullandığımız isimli bir kutudur. Programın bir yerde ölçtüğü ya da hesapladığı değeri başka bir yerde kullanabilmesi için o değeri bir yere koyması gerekir. Değişkenler bize üç kolaylık sağlar:

  1. Değer saklama: Butonun durumu, potansiyometrenin okunan değeri gibi bilgileri tutarız.
  2. Okunabilirlik: digitalWrite(13, HIGH) yerine digitalWrite(ledPin, HIGH) yazmak, kodun ne yaptığını açıkça gösterir.
  3. Kolay değişiklik: LED'i 13. pinden 8. pine taşıdığınızda kodun her yerini değil, sadece değişkenin değerini değiştirirsiniz.

Değişken nasıl yazılır?

Genel yazım şekli şöyledir: önce tür, sonra isim, isteğe bağlı olarak ilk değer.

tür isim = değer;
int ledPin = 13;          // tam sayı
float sicaklik = 24.5;    // ondalıklı sayı
bool butonBasili = false; // doğru / yanlış
char harf = 'A';          // tek karakter
int sayac;                // değer verilmeden tanımlandı

sayac = 0;                // sonradan değer atandı
sayac = sayac + 1;        // değeri 1 artırıldı (sayac++ ile aynı)

İsimlendirme kuralları:

  • Harf veya alt çizgi ile başlar; rakamla başlayamaz (2led hatalı).
  • Boşluk ve Türkçe karakter (ç, ğ, ı, ö, ş, ü) kullanılmaz: sıcaklık yerine sicaklik.
  • int, void, if gibi ayrılmış kelimeler isim olamaz.
  • Anlamlı isim seçin. Birden çok kelime için potDegeri gibi "camelCase" yazım yaygındır. Yani ilk kelime küçük ikinci kelimenin ilk harfi büyük yazım şekli

Değişken türleri

Tür, değişkenin ne tür bir veri tutacağını ve bellekte ne kadar yer kaplayacağını belirler. UNO'da 2 KB gibi çok küçük bir RAM olduğu için doğru türü seçmek önemlidir.

Program boyunca değişmeyecek değerlerin başına const yazılır: const int ledPin = 13;. Böylece değer yanlışlıkla değiştirilemez, derleyici de belleği daha verimli kullanır. Pin numaraları için en doğru tercih budur.

Kapsam: değişkeni nereye yazmalı?

  • Global değişken: Tüm fonksiyonların dışında, dosyanın en üstünde tanımlanır. setup() ve loop() dahil her yerden erişilir. Pin numaraları ve loop'un her turunda değerini koruması gereken veriler (sayaç, LED durumu) burada tanımlanır.
  • Yerel değişken: Bir fonksiyonun içinde tanımlanır, yalnızca orada geçerlidir. loop() içinde tanımlanan yerel değişken her turda yeniden oluşur.
kapsam.ino
const int ledPin = 13;   // global: her yerden erişilir
int sayac = 0;           // global: değerini korur

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int okunan = analogRead(A0);  // yerel: sadece loop içinde geçerli
  sayac = sayac + 1;
  Serial.println(sayac);
  delay(500);
}

Bölüm 04

pinMode(): giriş mi, çıkış mı?

Dijital pinler hem giriş hem çıkış olabildiği için, bir pini kullanmadan önce Arduino'ya o pinin görevini söylememiz gerekir. Bu ayar genelde setup() içinde, bir kez yapılır.

pinMode(pin, mod);
pinMode(13, OUTPUT);        // 13. pin çıkış
pinMode(2, INPUT);          // 2. pin giriş
pinMode(3, INPUT_PULLUP);   // 3. pin giriş, dahili pull-up direnci açık

Karar vermenin kolay yolu şu soruyu sormaktır: Bilgi Arduino'ya mı geliyor, yoksa Arduino bir şeyi mi çalıştırıyor?

INPUT Arduino'ya bilgi gelir

  • Buton, anahtar (switch)
  • Hareket sensörü (PIR)
  • Engel / kızılötesi sensör
  • Limit (sınır) anahtarı
  • Eğim sensörü, reed röle
  • Ultrasonik sensörün Echo pini

OUTPUT Arduino bir şeyi sürer

  • LED, RGB LED
  • Buzzer
  • Röle modülü
  • Transistör / motor sürücü girişi
  • 7 segment gösterge
  • Ultrasonik sensörün Trig pini

Üç mod

ModAnlamı
OUTPUTPin 5 V veya 0 V verir. digitalWrite() ve analogWrite() ile kullanılır.
INPUTPin gerilimi okur. Pin boşta kalırsa okunan değer rastgele değişir, bu yüzden harici bir pull-down veya pull-up direnci gerekir.
INPUT_PULLUPGiriş + kartın içindeki yaklaşık 20–50 kΩ'luk direnç pini 5 V'a çeker. Harici direnç gerekmez. Buton basılı değilken HIGH, basılıyken LOW okunur (ters mantık).
Bilmekte fayda var

A0–A5 pinlerini analogRead() ile okurken pinMode yazmaya gerek yoktur. analogWrite() da pini kendisi çıkış yapar; yine de pinMode(pin, OUTPUT) yazmak kodu okuyan kişi için açıklayıcıdır.

Bölüm 05

digitalWrite(): pini aç / kapat

OUTPUT olarak ayarlanmış bir pine HIGH (5 V) ya da LOW (0 V) verir.

digitalWrite(pin, deger);
digitalWrite(13, HIGH);  // 13. pine 5 V ver, LED yanar
digitalWrite(13, LOW);   // 13. pine 0 V ver, LED söner

İlk program: Blink (yanıp sönen LED)

Kart üzerindeki L LED'ini birer saniye arayla yakıp söndürür. Hiçbir devre kurmadan deneyebilirsiniz.

blink.ino
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);  // LED'i yak
  delay(1000);                 // 1000 ms = 1 saniye bekle
  digitalWrite(ledPin, LOW);   // LED'i söndür
  delay(1000);
}

delay(ms) programı verilen milisaniye kadar bekletir. delay(1000) bir saniyedir.

Bölüm 06

digitalRead(): pinin durumunu oku

INPUT veya INPUT_PULLUP olarak ayarlanmış bir pinin o anki durumunu okur ve HIGH ya da LOW döndürür. Okunan değeri genelde bir değişkende saklarız.

deger = digitalRead(pin);
const int butonPin = 2;
int butonDurumu = 0;

void setup() {
  pinMode(butonPin, INPUT);
  Serial.begin(9600);       // Seri haberleşmeyi 9600 baud hızında başlat
}

void loop() {
  butonDurumu = digitalRead(butonPin);
  Serial.println(butonDurumu);  // Basılıysa 1, değilse 0 yazar
  delay(100);
}

Sonucu görmek için Arduino IDE'de Araçlar › Seri Port Ekranı'nı açın ve hızı 9600 baud seçin. Serial.println() değeri yazar ve alt satıra geçer.

Neden direnç gerekiyor?

Boşta kalan (hiçbir yere bağlı olmayan) bir giriş pini çevredeki elektriksel gürültüden etkilenir; elinizi yaklaştırsanız bile 0 ile 1 arasında rastgele değişir. Buna floating (havada kalma) denir. Pull-down ya da pull-up direnci, buton basılı değilken pini belirli bir seviyede tutar. Bağlantısı Bölüm 08'de.

Bölüm 07

if / else yapısı: karar verme

Program bir koşula göre farklı işler yapacaksa if (eğer) kullanılır. Koşul doğruysa süslü parantez içindeki kodlar çalışır; yanlışsa else (değilse) bloğu çalışır.

yapı
if (kosul) {
  // koşul doğruysa çalışır
} else {
  // koşul yanlışsa çalışır
}

İkiden fazla durum varsa else if ile koşullar zincirlenir. Arduino yukarıdan aşağı bakar ve ilk doğru koşulu çalıştırır:

else-if.ino
int deger = analogRead(A0);

if (deger < 300) {
  Serial.println("Dusuk");
} else if (deger < 700) {
  Serial.println("Orta");
} else {
  Serial.println("Yuksek");
}

Bölüm 08 Uygulama

Buton ile LED yakma devresi

Şimdiye kadar öğrendiklerimizi birleştiriyoruz: pinMode, digitalRead, if/else ve digitalWrite. Butona basılıyken LED yanacak, bırakınca sönecek.

LED nasıl bağlanır?

  • LED'in uzun bacağı anot (+), kısa bacağı katot (−)'tur. Katot tarafında LED'in gövdesi de düzdür.
  • Anot, 220 Ω (veya 330 Ω) direnç üzerinden Arduino pinine bağlanır. Direnç LED'den geçen akımı sınırlar; dirençsiz bağlanan LED ve pin zarar görebilir.
  • Katot GND'ye bağlanır.

Buton nasıl bağlanır?

  • Breadboard'a takılan 4 bacaklı butonlarda bacaklar ikişer ikişer içeriden birbirine bağlıdır. Butonu breadboard'un ortasındaki kanalın üzerine yerleştirin; çapraz bacakları kullanırsanız her zaman doğru iki ucu seçmiş olursunuz.
  • İki bağlantı yöntemi vardır: harici pull-down direnci ile veya dahili INPUT_PULLUP ile.

Yöntem 1: 10 kΩ pull-down direnci ile

Butonun bir ucu 5V'a, diğer ucu hem D2 pinine hem de 10 kΩ direnç üzerinden GND'ye bağlanır. Basılı değilken direnç pini GND'ye çeker (LOW), basınca pin 5V'a bağlanır (HIGH).

buton_led_pulldown.ino
const int butonPin = 2;   // buton D2'de
const int ledPin = 13;    // LED D13'te
int butonDurumu = 0;      // okunan değer burada saklanır

void setup() {
  pinMode(butonPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  butonDurumu = digitalRead(butonPin);

  if (butonDurumu == HIGH) {     // butona basıldıysa
    digitalWrite(ledPin, HIGH);  // LED'i yak
  } else {
    digitalWrite(ledPin, LOW);   // LED'i söndür
  }
}

Yöntem 2: INPUT_PULLUP ile (dirençsiz)

Kartın içindeki pull-up direncini kullanırsak buton için harici direnç gerekmez. Butonun bir ucu D2'ye, diğer ucu doğrudan GND'ye bağlanır. Mantık terstir: basılı değilken HIGH, basılıyken LOW okunur.

buton_led_pullup.ino
const int butonPin = 2;
const int ledPin = 13;

void setup() {
  pinMode(butonPin, INPUT_PULLUP);  // dahili direnç açık
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int butonDurumu = digitalRead(butonPin);

  if (butonDurumu == LOW) {      // DİKKAT: basılıyken LOW okunur
    digitalWrite(ledPin, HIGH);
  } else {
    digitalWrite(ledPin, LOW);
  }
}

Geliştirme: her basışta LED durumunu değiştir

Butona bir kez basınca LED yanık kalsın, tekrar basınca sönsün istiyorsak LED'in durumunu bir bool değişkende hatırlamamız ve basılma anını yakalamamız gerekir. Butonun kontakları basıldığı anda birkaç milisaniye titreştiği (sıçrama, "bounce") için kısa bir bekleme ekliyoruz.

buton_toggle.ino
const int butonPin = 2;
const int ledPin = 13;
bool ledAcik = false;      // LED'in durumu
int oncekiButon = HIGH;    // bir önceki turdaki buton değeri

void setup() {
  pinMode(butonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  int simdikiButon = digitalRead(butonPin);

  // HIGH'dan LOW'a geçiş = butona basıldığı an
  if (oncekiButon == HIGH && simdikiButon == LOW) {
    ledAcik = !ledAcik;              // durumu tersine çevir
    digitalWrite(ledPin, ledAcik);
    delay(50);                       // sıçrama (debounce) önlemi
  }

  oncekiButon = simdikiButon;
}
Bölüm 09

analogRead(): gerilimi sayıya çevir

Dijital okuma sadece "var / yok" söyler. Bir sensörün ne kadar değer verdiğini öğrenmek için analog okuma yaparız. analogRead(), A0–A5 pinlerinden birindeki 0–5 V arası gerilimi 0 ile 1023 arasında bir tam sayıya çevirir.

deger = analogRead(pin);
int deger = analogRead(A0);   // 0 ... 1023 arası bir sayı

Neden 1023? UNO'daki analog-dijital çevirici (ADC) 10 bitliktir. 10 bit ile 210 = 1024 farklı değer gösterilebilir: 0'dan 1023'e. Her adım yaklaşık 5 V / 1024 ≈ 4,9 mV'a karşılık gelir.

Pindeki gerilimanalogRead sonucu
0 V0
1,25 V≈ 256
2,5 V≈ 512
3,75 V≈ 767
5 V1023

Okunan sayıyı tekrar volta çevirmek için:

gerilim hesabı
int deger = analogRead(A0);
float gerilim = deger * (5.0 / 1023.0);   // 5.0 yazmak önemli: ondalıklı bölme yapar
Neden 5.0?

5 / 1023 iki tam sayının bölümüdür ve sonucu 0 olur. 5.0 / 1023.0 yazınca bölme ondalıklı yapılır.

Bölüm 10 Uygulama

Potansiyometre ile analog okuma

Potansiyometre, mili çevrildikçe direnci değişen ayarlı bir dirençtir. Üç bacağı vardır. İki dış bacağa 5V ve GND verildiğinde, orta bacak (sürgü, "wiper") mili çevirdikçe 0 ile 5 V arasında bir gerilim verir. Bu gerilimi analog pinden okuruz.

Bağlantı

  • Dış bacaklardan biri → 5V
  • Diğer dış bacak → GND
  • Orta bacak → A0

Dış bacakları yer değiştirirseniz sadece dönüş yönü tersine döner; devre yine çalışır.

pot_okuma.ino
const int potPin = A0;
int potDegeri = 0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  potDegeri = analogRead(potPin);
  float gerilim = potDegeri * (5.0 / 1023.0);

  Serial.print("Deger: ");
  Serial.print(potDegeri);
  Serial.print("   Gerilim: ");
  Serial.print(gerilim);
  Serial.println(" V");

  delay(200);
}
Grafik olarak izleyin

Arduino IDE'de Araçlar › Seri Çizici (Serial Plotter) açılırsa Serial.println(potDegeri); ile gönderilen değerler canlı grafik olarak görünür. Mili çevirdikçe çizginin yükselip alçaldığını izleyin.

Bölüm 11

analogWrite() ve PWM

digitalWrite() ile bir LED ya tam yanar ya söner. Yarı parlaklık için analogWrite() kullanılır. Bu fonksiyon gerçekte 2,5 V gibi ara bir gerilim üretmez; bunun yerine pini saniyede yaklaşık 490 kez (5 ve 6. pinlerde ≈ 980 kez) açıp kapatır. Göz bu hızı ayırt edemez ve LED'i ortalama parlaklıkta görür. Bu yönteme PWM denir.

analogWrite(pin, deger);
analogWrite(9, 0);     // her zaman kapalı  →  %0
analogWrite(9, 64);    // zamanın ~%25'i açık
analogWrite(9, 127);   // zamanın ~%50'si açık
analogWrite(9, 255);   // her zaman açık    →  %100
  • Değer aralığı 0–255'tir (8 bit). analogRead'in 0–1023 aralığından farklı olduğuna dikkat edin.
  • Sadece ~ işaretli pinlerde çalışır: 3, 5, 6, 9, 10, 11.
  • Pinin açık kaldığı sürenin bir periyoda oranına görev oranı (duty cycle) denir.

Örnek: yavaşça yanıp sönen LED (fade)

LED'i bir PWM pinine (örneğin D9) 220 Ω direnç üzerinden bağlayın. Parlaklık değişkeni her turda biraz artar; sınıra gelince yön değiştirir.

fade.ino
const int ledPin = 9;    // ~9 PWM pini
int parlaklik = 0;
int adim = 5;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  analogWrite(ledPin, parlaklik);
  parlaklik = parlaklik + adim;

  if (parlaklik <= 0 || parlaklik >= 255) {
    adim = -adim;          // sınıra gelince yönü ters çevir
  }
  delay(30);
}
Bölüm 12 Uygulama

map() fonksiyonu ve dimmer devresi

Şimdi potansiyometreyi çevirerek LED'in parlaklığını ayarlayacağız. Bir sorun var: analogRead() 0–1023 arası değer verir, analogWrite() ise 0–255 arası değer ister. Bir aralıktaki sayıyı diğer aralığa orantılı olarak çevirmek için map() fonksiyonu kullanılır.

map(deger, eskiMin, eskiMax, yeniMin, yeniMax)
int parlaklik = map(potDegeri, 0, 1023, 0, 255);
// 0    → 0
// 512  → 127
// 1023 → 255

map() şu hesabı yapar: (deger − eskiMin) × (yeniMax − yeniMin) / (eskiMax − eskiMin) + yeniMin. Birkaç ayrıntı:

  • Tam sayı ile çalışır; ondalık kısmı atar (127,6 → 127).
  • Ters çevirmek mümkündür: map(potDegeri, 0, 1023, 255, 0) ile pot çevrildikçe LED kısılır.
  • Başka aralıklar için de kullanılır: yüzdeye çevirmek için map(potDegeri, 0, 1023, 0, 100), servo açısı için map(potDegeri, 0, 1023, 0, 180).
  • Sonucu sınırlamaz. Giriş aralığın dışına çıkabiliyorsa constrain(sonuc, 0, 255) ile sınırlayın.

Dene: potansiyometreyi çevir

Kaydırıcı potansiyometrenin milini temsil eder. Değerlerin analogRead'den map'e, oradan PWM sinyaline nasıl geçtiğini izleyin.

Dimmer devresinin bağlantısı

  • Potansiyometre: dış uçlar 5V ve GND, orta uç A0 (Bölüm 10'daki gibi).
  • LED: anot 220 Ω direnç üzerinden D9'a (PWM pini olmalı), katot GND'ye.
dimmer.ino
const int potPin = A0;   // potansiyometre orta ucu
const int ledPin = 9;    // ~ işaretli PWM pini

int potDegeri = 0;       // 0 ... 1023
int parlaklik = 0;       // 0 ... 255

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  potDegeri = analogRead(potPin);                  // 1) oku
  parlaklik = map(potDegeri, 0, 1023, 0, 255);     // 2) çevir
  analogWrite(ledPin, parlaklik);                  // 3) yaz

  Serial.print("Pot: ");
  Serial.print(potDegeri);
  Serial.print("   Parlaklik: ");
  Serial.println(parlaklik);

  delay(10);
}
map() olmadan da olur mu?

0–1023 aralığı 0–255 aralığının yaklaşık 4 katı olduğu için parlaklik = potDegeri / 4; da aynı sonucu verir. map() ise her aralık için çalıştığından daha genel bir çözümdür.

Ek: eşik değerle if/else

Analog değeri if ile de kullanabiliriz. Örneğin pot yarının üstüne çevrilince LED yansın:

esik.ino
void loop() {
  int potDegeri = analogRead(A0);

  if (potDegeri > 512) {
    digitalWrite(9, HIGH);
  } else {
    digitalWrite(9, LOW);
  }
}
